# Mohamed Ezz — Portfolio

Terminal-aesthetic developer portfolio built with vanilla HTML, CSS, and JavaScript. No frameworks, no build tools.

## Tech Stack

- **HTML5** — semantic markup, accessible
- **CSS3** — custom properties, grid, animations
- **JavaScript** — vanilla, no dependencies

## Features

- Interactive terminal with typewriter effect
- Canvas starfield + floating code fragments background
- Animated section reveals (IntersectionObserver)
- Responsive design (mobile → desktop)
- Light mode easter egg
- Contact form via Formspree
- Terminal-style navigation and UI components

## Sections

- **Hero** — intro with live terminal window
- **About** — bio and stats
- **Skills** — tree-view skill categories
- **Projects** — indexed project cards with tags
- **Experience** — timeline log
- **Achievements** — verified accomplishments
- **Contact** — form + direct links

## Run Locally

```bash
# No build step needed — just open in a browser
start index.html
```

Or use a local server:

```bash
npx serve .
```
